# Broader Public Beta launch checklist

## Product readiness

- [ ] Final release regression passes from a clean production build.
- [ ] Mission, organization, technology, Public Need and Defence Brief routes return current published data.
- [ ] Map, filters, Ask True North and Working Lists complete their primary workflows.
- [ ] Authentication, contributions, connections, feedback and North Signal capture pass production smoke tests.
- [ ] Security, privacy, retention, RLS and rate-limit checks have no unresolved launch blocker.

## Content readiness

- [ ] Featured records have working public citations and no unsupported claims.
- [ ] Pending publication, match, contribution, connection and contact queues have been reviewed.
- [ ] Current coverage gaps are visible and described plainly.
- [ ] Launch screenshots and partner materials match the production release candidate.
- [ ] No fixed corpus count appears in reusable copy.

## Channel readiness

- [ ] Andrew's founder post and one current screenshot are ready.
- [ ] True North Map LinkedIn page copy and banner are ready.
- [ ] True North Map LinkedIn and X accounts have the approved Directional N avatar, the correct header treatment, canonical website link and Andrew as the sole administrator.
- [ ] X uses app-based two-factor authentication; recovery codes and the unique password are retained only in Andrew's password manager.
- [ ] Personal, included-organization, ecosystem, media and community messages are channel-specific.
- [ ] Each shared link uses a valid UTM campaign and current social card.
- [ ] MailerLite sender, North Signal group, welcome email and unsubscribe path are verified.

## Release sequence

1. Publish the production release and complete a fresh-browser smoke test.
2. Share through Andrew's LinkedIn, the True North Map LinkedIn Page and the True North Map X account.
3. Send personal notes to trusted users and organizations represented in the map.
4. Contact Canadian ecosystem organizations and selected media with tailored context.
5. Share in builder and public communities only after checking current promotion rules.
6. Monitor search behaviour, profile opens, shares, North Signal subscriptions, contributions, connections, errors and direct feedback. Review native social analytics and consent-respecting UTM traffic at 30 and 60 days; do not start paid promotion automatically.

## Stop conditions

Stop promotion if the release exposes private data, breaks a primary discovery or authentication workflow, fails consent or unsubscribe handling, returns recurring unexplained server errors, or presents an unsupported featured claim.
