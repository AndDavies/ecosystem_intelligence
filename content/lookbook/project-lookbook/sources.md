## Public-safe disclosure rules

The lookbook intentionally excludes:

- credentials, environment values and private service identifiers;
- administrator identity controls;
- exact security policy implementation or unresolved exploit detail;
- subscriber identities, raw search queries and user records;
- raw newsletter content, private wiki packets and internal correspondence;
- visibility-provider credentials, raw exports, referrer data and query evidence;
- unpublished candidate content and internal reviewer instructions.

The document describes application security controls but does not claim an independent penetration test, formal certification or government endorsement.
