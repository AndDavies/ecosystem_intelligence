# Source Routing

| Need | First route | Fallback | Evidence posture |
| --- | --- | --- | --- |
| Gmail defence newsletters | Gmail connector, label `Newsletters/Defence` | Record connector warning | Discovery only |
| LinkedIn company/program activity | Authenticated Chrome, targeted URL or query | Public company newsroom/search | Discovery only |
| JavaScript procurement/marketplace | Chrome read-only | Official static page/API/search resolution | Official page can anchor evidence |
| Company products/news | Canonical company pages | Reputable publication leading to company page | Official page preferred |
| Government demand/contracts | Official issuer, CanadaBuys, departmental program | Reputable attributable reporting | Official page preferred |
| Source Book due rows | Recorded access method | Public web/Chrome | Follow row posture |

Never perform social actions. Strip tracking parameters and retain redirects only as provenance. Search LinkedIn by named organization, technology, program, procurement term, or company-page activity—not by scrolling the general feed.
