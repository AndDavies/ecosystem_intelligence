# Project Context

Use [AGENTS](../AGENTS.md) for task routing and [governance/INDEX.md](governance/INDEX.md) to locate a maintained responsibility. Read only what the task needs.

Governance holds product requirements, specialist contracts and dated decision history. Plans coordinate multi-session work; proposals and historical receipts are not active instructions. Private operator procedure lives in ignored `.agents/skills/` at the repository root. File placement is described in the root README. The Codex Workflow Contract owns the affected-dependency maintenance rule.
